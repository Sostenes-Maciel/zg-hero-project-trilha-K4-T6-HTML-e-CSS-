# 🎮 Currículo Web — Sóstenes Maciel

## Sobre o projeto

Este projeto consiste em um currículo desenvolvido como página web, com uma interface inspirada em videogames. O objetivo é apresentar minhas informações profissionais, habilidades, formação acadêmica, projetos e certificados de forma criativa e interativa.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git e GitHub
- GitHub Pages

## Funcionalidades

- Layout com temática gamer;
- Animações utilizando CSS;
- Seções para apresentação, habilidades, projetos, certificados e contato;
- Layout responsivo para diferentes tamanhos de tela;
- Publicação gratuita pelo GitHub Pages.
